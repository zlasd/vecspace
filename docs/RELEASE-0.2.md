# VecSpace 0.2：现有工具选项扩展

日期：2026-09-05。仓库：`/Users/zlasd/repo/vecspace`。

## 选项变化

| 工具 | 新增选项 |
| --- | --- |
| UUID | v1/v3/v4/v5/v6/v7、Nil/Max；DNS/URL/OID/X.500/自定义命名空间；每行一个名称；标准/无连字符/URN/花括号；大小写；最多 10,000 个 |
| 哈希 | 18 种算法：MD5、SHA-1、SHA-224/256/384/512、SHA3-224/256/384/512、Keccak-256、BLAKE2b-512、BLAKE2s-256、BLAKE3-256、RIPEMD-160、SM3、CRC32、Adler-32；摘要 Hex/大写 Hex/Base64/Base64URL；文本按 UTF-8/Hex/Base64/Base64URL 解释 |
| 密钥 | RSA-PSS、RSASSA-PKCS1-v1_5、RSA-OAEP、ECDSA、ECDH、Ed25519、X25519；RSA 2048/3072/4096/8192；EC P-256/P-384/P-521；RSA 摘要 SHA-256/384/512 |
| 签名与验签 | RSA-PSS、RSA PKCS1、ECDSA、Ed25519；PSS 盐长度；SHA-256/384/512；ECDSA P1363/DER；Base64/Base64URL/Hex；同一参数集用于公私钥配对 |
| Base64 | UTF-8/UTF-16LE/UTF-16BE/Latin-1 文本；解码另支持 GB18030/Shift_JIS/Big5/Windows-1252；填充保留/省略；64/76 字符换行 |
| URL | RFC3986 严格组件编码、逐行批量、JSON 键值对构建查询参数，保留重复参数 |
| JSON | 2/4/8 空格或 Tab 缩进、递归排序键、非 ASCII 转义；保留数字精度 |
| 时间戳 | 秒/毫秒/微秒/纳秒精确十进制互转；ISO 输入/输出保留最多 9 位小数秒；IANA 输出时区 |
| 文本 | Unicode NFC/NFD/NFKC/NFKD、大小写、合并空白、自然排序、反转、每行前后缀、CR/LF/CRLF |
| PDF 预览 | 25%–400% 缩放、左右旋转预览 |
| PDF 合并 | 文件名自然排序、反转文件顺序、扩展页码范围、输出文件名前缀 |
| PDF 拆分 | 分号分隔自定义分组，例如 `1-3;4,6;7-last` |
| PDF 整理 | 反转页序、全部旋转、保留原奇数/偶数页、移除重复页 |
| 图片转 PDF | A3/A4/A5/Letter/Legal/Tabloid/原尺寸/自定义 mm 尺寸；DPI；自动方向；只缩小不放大；更大边距 |
| PDF 转图片 | PNG/JPEG/WebP；0.25–6 倍率；有损质量；PNG/WebP 透明背景；输出文件名前缀 |

页码语法统一支持空值/all、odd/even、last、开放范围 `3-` / `-5`，以及原有逗号、顺序、重复和倒序范围。

## 限制调整

| 项目 | 原值 | 新值 |
| --- | --- | --- |
| PDF 输入合计 | 50 MiB | 512 MiB |
| PDF 页面 | 300 | 5,000 |
| 图片输出合计 | 150 MiB | 512 MiB |
| 单张图像 | 1600 万像素 | 6400 万像素 |
| 哈希文件 | 50 MiB | 2 GiB，4 MiB 分块读取 |
| 普通编解码/签名文件 | 50 MiB | 64 MiB |
| 文本 | 2 MiB | 16 MiB |
| UUID 批量 | 1,000 | 10,000 |

大 PDF 保存原始 File、在 Worker 中读取，合并时逐个解析，输出采用可转移缓冲区减少复制。缩略图仍每次渲染 8 页。限制是保护阈值，实际容量取决于设备内存；没有把 512 MiB/5,000 页宣称为各浏览器都能完成的性能保证。

## 验证

- 116 项自动化测试：保留原有测试，并增加 RFC UUID 向量、18 种哈希、流式文件读取、DER 与 OpenSSL 互操作、RSA-OAEP/ECDH/X25519 导出密钥可用性、纳秒精度与各选项的 Worker/界面传递。
- 350 页 PDF 的拆分与合并测试通过，确认旧 300 页限制已解除。
- TypeScript 和生产构建通过；中英切换继续不改 URL，并保留输入与结果。
- 仍未进行真实浏览器视觉检查和设备内存压力测试；未部署站点或修改 DNS。

MD5/SHA-1 和普通校验和用于兼容性场景；界面不将它们作为密码存储或安全签名算法。Ed25519/X25519 等原生能力仍取决于浏览器，未支持时返回明确错误。
