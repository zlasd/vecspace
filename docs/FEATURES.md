# 功能清单

更新时间：2026-09-05。以下均为规划功能，尚未实现。

## 阶段定义

- **P0**：首版范围，优先打磨可靠性和统一交互。
- **P1**：首版后的常用扩展。
- **P2**：需要专项验证的高级能力；不承诺完整格式兼容或实现时间。

表中引擎为候选实现思路，最终版本与浏览器兼容性在接入时验证。

## 共享功能

- **P0**：分类目录、搜索、独立工具入口、复制/下载、清空、明确输入输出格式、错误提示、键盘可达、窄屏适配。
- **P0**：文件大小和页数检查、任务进度、取消、逐项失败信息；文件清单只存在于当前任务内存。
- **P0**：默认不保存用户输入和密钥，不把内容放入 URL、日志、分析事件或错误上报。
- **P1**：收藏与偏好仅保存工具 ID/设置；可清除本地数据。
- **P1**：PWA、模块离线下载、缓存体积展示、版本更新和清理。
- **P1**：统一批处理队列与批量下载；避免重型任务无上限并发。
- **P2**：串联工具工作流，例如图片 → OCR → 文本整理；只传递显式选择的本地结果。

## 信息架构

计划使用 `/developer/<tool-id>` 与 `/documents/<tool-id>`；路由实现和静态托管回退策略在应用搭建阶段验证。

JSON、编码、密钥等面向程序语义的处理归开发者工具；普通文本编辑、办公数据文件与文档处理归文档工具。跨类别可以通过搜索标签发现，共享底层实现，不复制工具。

## 当前范围之外

游戏模拟器、音视频转换、用户账户、云同步、在线协作与服务端文件处理均不进入当前两类工具的交付计划。未来可通过新增分类接入。

技术能力与限制的来源见 [技术资料](REFERENCES.md)。
