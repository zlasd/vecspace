# VecSpace 0.1 交付记录

日期：2026-09-05。代码位于 `/Users/zlasd/repo/vecspace`，静态构建输出位于该仓库的 `dist/`。

## 本次交付

- 8 项开发者工具：Base64/Base64URL、URL、JSON、UUID v4、时间戳、SHA 哈希、密钥生成、签名/验签与密钥配对。
- 7 项文档工具：PDF 预览、合并、拆分/提取、页面整理、图片转 PDF、PDF 转图片、文本整理。
- 中英文界面与搜索。浏览器语言自动检测、手动切换与本地偏好记忆；不改变 URL 的路径、查询参数或片段。
- 语言切换保留输入、文件、结果和任务状态；切换工具或清空会释放当前任务。
- 计算在浏览器完成。PDF 解析和处理使用 Worker；渲染资源、字体和 Wasm 解码器同源加载。
- 可取消的计算任务与 ZIP 打包；错误文件单独显示，批量导入中的可读文件可以继续处理。
- React + TypeScript + Vite；npm 锁文件、构建脚本、静态托管规则与依赖声明齐全。

## 自动化验证

66 项测试覆盖：

- RFC 4648 编码向量、非法填充和 UTF-8、二进制文件往返。
- JSON 大整数及数字词法保持、非法 JSON、查询参数重复值、时间单位/时区和无效日期。
- SHA-256/384/512 与独立实现对照；RSA-PSS、ECDSA 与 Node/OpenSSL 签名互操作；篡改内容和错误密钥验证失败。
- PDF 页序、重复、旋转、混合尺寸、拆分组数、图片嵌入和原始字节保持不变。
- PDF.js 在 Node Canvas 环境的实际栅格化、像素结果及 PNG 编码，渲染前取消与像素限制。
- React 组件状态：语言切换保留 URL、输入、错误和文档结果；存储不可用时仍可切换；有效文件与加密错误文件混合导入。
- Worker 实际消息协议与生命周期：进度、结果、错误、取消、忽略过期结果、重试和组件卸载清理。

`npm test`、`npm run check` 和 `npm run build` 均已通过。生产预览的 18 个路由、7 个应用资源及全部 PDF 资源 HTTP 检查通过；JavaScript/Wasm MIME 正确。生产依赖审计未报告已知漏洞；这不替代安全审计。

## 验证范围与后续事项

- 本次完成引擎和组件测试、静态构建及本地 HTTP 路由/资源检查；没有执行真实 Chrome/Firefox/Safari 的界面点击验收、视觉检查或移动设备内存基准。
- 保守资源限制：文本 2 MiB、输入合计 50 MiB、300 页、单张图像 1600 万像素、图片输出合计 150 MiB。这些是保护阈值，不是实测性能承诺。
- 加密 PDF、完整离线/PWA、OCR、Word/表格工具和高级文档转换仍属于后续阶段。
- 首版生成密码学签名，不提供 PDF 证书数字签名。
- 尚未部署到 `vec.im`，没有修改 DNS 或创建远程代码仓库。静态发布是独立交付动作。

## 本地使用

```sh
cd /Users/zlasd/repo/vecspace
npm ci
npm run dev
```

构建与生产预览：

```sh
npm run build
npm run preview
```

安装会从锁定的依赖生成同源 PDF 引擎资源和第三方声明。不要通过 `file://` 双击构建文件，使用本地 HTTP 服务器或 HTTPS 静态托管。
